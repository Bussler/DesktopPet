Use the exact candidate executable and hashes in the [acceptance record](../../docs/specs/Notes-Writing-Animations-ACCEPTANCE.md). Close older running copies first. Use a separate data profile when convenient so tests do not change daily notes or care progress.

- [x] The user acknowledged the four custom artwork loops in this chat: Hood/Pip notebooks, Crumb keyboard, Puddle ground writing.
- [ ] In each pet, physically type in an empty note and existing rich content, the title, and inline/display formula source. Check prompt response, recognizable motion, stable scale/props and smooth transitions. Pause and verify return after about 0.8 seconds. Slow typing and held/repeated keys should sustain a continuous loop rather than restart its first pose.
- [ ] Check characters/spaces, Enter, Tab, Backspace/Delete, Ctrl+V and Shift+Insert. Navigation/modifiers alone, copy/format/undo commands alone, mouse selection/scroll/paste, search/settings typing and merely focusing a note must not start or extend writing. Verify real clipboard contents and ordinary editor commands remain correct.
- [ ] Leave the field, switch notes/apps, enter/leave a formula, and use Ctrl+Enter to leave formula source: writing stops immediately and waits for new input. Close, hide (with and without the Notes transition), delete and reopen notes; no stale response may remain.
- [ ] Test all four combinations of idle/writing options, with roaming and occasional reactions on/off. Save/relaunch retains explicit choices; Cancel/window close do not apply them. Check label/keyboard focus/theme readability in all supported styles and at minimum settings size.
- [ ] While typing, verify roaming pauses without relocation and becomes available again when typing ends. Feed, click/pet, drag and legitimate naps take priority. Automatic naps still occur. If a care action ends, writing resumes only for still-current typing.
- [ ] During normal focus, Notes typing works. Focus-completion waving and running/paused/finished break sleep remain authoritative. Checklist ticking to done still celebrates; unchecking does not. Check the existing Notes/Focus click behavior remains intact.
- [ ] Hide sprites while Notes stay visible, type, then reveal: hidden activity is not replayed. Suspend/resume and Quit/relaunch discard typing activity while preserving notes and legitimate pet state. Test near-immediate suspend/resume as well as a longer sleep.
- [ ] Switch/preview all pets, Save, Cancel, close without saving and recover from a failed save. Check subsequent typing uses the selected pet, with no wrong frames. Check headphones/earbuds during real supported audio playback, resizing 50%-200%, common display scaling and movement between monitors; inspect clipping, transparency, hit targets and accessory alignment.
- [ ] Load representative valid older replacement artwork without writing poses. It stays usable, uses idle artwork while typing, respects the idle-animation option for that fallback and can switch back to packaged pets.
- [ ] Edit prose, lists/checklists, code, tables and formulas; use undo/redo and save/reload. Confirm accepted text, formatting, caret/selection, scroll behavior, immediate saves and existing save-error/retry recovery are preserved. Confirm responsive typing under representative use.

Keep unperformed checks pending. The artwork acknowledgement does not claim packaged physical-keyboard, clipboard, focus, mixed-DPI or audio-delivery acceptance. Record any failure with the candidate path, pet, relevant options and repeatable steps.
