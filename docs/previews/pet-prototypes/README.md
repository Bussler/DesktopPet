# Alternate pet previews

Static sprite concepts for visual substitutes for Hood, generated with the built-in imagegen tool on 2026-10-05.

- `pip-preview.png`: selected Pip design, wearing the forest-green wool shawl.
- `pip-cape-preview.png`: alternate Pip with a dark-blue cape.
- `pip-shawl-preview.png`: alternate Pip with a plum shawl.
- `pip-green-wool-shawl-preview.png`: approved Pip with a forest-green wool neck wrap and fringed ends, based on the supplied photo reference. Use this design going forward.
- `puddle-preview.png`: Puddle the slime, without accessories.
- `crumb-preview.png`: Crumb the mouse, wearing a mustard-yellow sweater.
- `crumb-hoodie-preview.png`: selected Crumb design, wearing a mustard hoodie with the hood down.

Each transparent PNG shows ten key poses. Read left to right: top row idle, run right, run left, wave, look up; bottom row look around, jump, feed, sleep, wake.

Pip and Crumb's feed poses hold a raised bowl in both paws while eating upright.

These static concepts cover Hood's existing actions and add no functionality. Complete animated replacements for the selected designs are now available in [the animation preview](../pet-animations/README.md). The runtime atlas uses a 16×10 grid of 384×416 cells with `spriteScale: 2`; see [changing sprites](../../changing-sprites.md).

Exact prompts and inspection notes are recorded in `.codex/pet-sprite-prototypes-2026-10-05.md` in the source checkout.
